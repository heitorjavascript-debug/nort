# NORTWAY Website

Static website built with HTML5, CSS3 and Vanilla JavaScript.

## Files
- index.html
- style.css
- script.js
- assets/

## Before publishing
Open `script.js` and edit the CONFIG object:
- whatsappNumber
- instagramUrl
- email

WhatsApp number must contain digits only, including country code and area code.

## Notes
The portfolio uses art-directed CSS visuals as replaceable placeholders, so no external stock-image dependency is required.
